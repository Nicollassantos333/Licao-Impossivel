🌐 Consulta de Endereço (Baseado no ViaCEP)

Consulte informações de endereço completas a partir de um número de CEP válido.

GET /api/cep/{cep}/json/

ParâmetroTipoDescrição
cepstringApenas números (ex: 01001000)

Exemplo de Resposta:

{
  "cep": "01001-000",
  "logradouro": "Praça da Sé",
  "bairro": "Sé",
  "localidade": "São Paulo",
  "uf": "SP"
}

👥 Controle de Usuários

Gerencie a autenticação, permissões e profiles de utilizadores do sistema.

POST /api/usuarios/registrar/

Cria uma nova conta de acesso à API e gera as credenciais iniciais.

GET /api/usuarios/perfil/

Retorna os dados do utilizador autenticado através do cabeçalho de Token JWT.

📦 Controle de Estoque

Endpoints para entrada, saída e atualização de produtos em inventário em tempo real.

PUT /api/estoque/atualizar/{id}/

CampoTipoObrigatório
quantidadeintegerSim
motivostringNão
