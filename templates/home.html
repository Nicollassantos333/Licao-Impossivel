👤 Cadastro de Usuário

Cria um novo usuário no sistema informando nome de usuário, senha, e-mail e data de nascimento.

POST /userprofile/register/

Parâmetro Tipo Descrição
username string Nome de usuário para login
password string Senha da conta
email string E-mail do usuário
birthdate string Data de nascimento no formato YYYY-MM-DD

Exemplo de Requisição:

{
  "username": "testuser1",
  "password": "123456",
  "email": "test@email.com",
  "birthdate": "2000-01-01"
}

Exemplo de Resposta:

{
  "status": "Sucesso",
  "message": "Usuário criado!"
}

🔐 Login

Autentica um usuário no sistema usando username e password.

POST /userprofile/login/

Parâmetro Tipo Descrição
username string Nome de usuário cadastrado
password string Senha do usuário

Exemplo de Requisição:

{
  "username": "testuser1",
  "password": "123456"
}

Exemplo de Resposta:

{
  "success": true,
  "message": "Login successful"
}

🙍 Visualizar Perfil

Retorna os dados do usuário autenticado. Esse endpoint exige que o usuário esteja logado.

POST /userprofile/view/

Requisito Tipo Descrição
Autenticação sessão Django Usuário deve estar autenticado para acessar esse endpoint
X-Requested-With header Use XMLHttpRequest para receber a resposta JSON

Exemplo de Resposta:

{
  "success": true,
  "usuario": {
    "id": 1,
    "username": "testuser1",
    "email": "test@email.com",
    "birthdate": "2000-01-01"
  }
}

📋 Listar Usuários

Lista todos os usuários cadastrados no sistema. Esse endpoint exige autenticação e acesso de usuário staff.

POST /userprofile/list/

Requisito Tipo Descrição
Autenticação sessão Django Usuário deve estar autenticado
Permissão staff Apenas usuários com is_staff = True podem acessar
X-Requested-With header Use XMLHttpRequest para receber a resposta JSON

Exemplo de Resposta:

{
  "success": true,
  "usuarios": [
    {
      "id": 1,
      "username": "testuser1",
      "email": "test@email.com",
      "birthdate": "2000-01-01"
    },
    {
      "id": 2,
      "username": "admin",
      "email": "admin@email.com",
      "birthdate": "1999-05-10"
    }
  ]
}
